# 42 evaluation sheets

A reference collection of 42 project evaluation sheets, stored as HTML pages and images, with a bundled NetPractice drill.

## Browse locally

Clone the repository and open an individual `index.html` in a browser, or serve the files with Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open <http://localhost:8000/> and browse the directory listing. For example, `3/Minishell/index.html` contains a project sheet and `4/NetPractice/drill/index.html` opens the bundled networking drill.

| Directory | Examples |
| --- | --- |
| `0/` | Initial evaluation material |

| `3/` | Minishell and Philosophers |

| `5/` | C++ modules 05–09, ft_irc, Inception, Webserv |
| `6/` | ft_transcendence |

Some entries are image-only; follow the files available in each directory. There is no root application build step.

## Reference status

These files are saved reference material, not a guarantee of the current official evaluation criteria. Check the active subject and evaluation sheet on the school platform when preparing a submission. The collection does not imply authorship of the original evaluation documents.
